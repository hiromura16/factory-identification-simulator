# プリセット一覧

通常12種類・異常12種類。各JSONはフォームで編集・保存できます。認証情報は含みません。

## 01-normal / 正常 / RFID通過 / 100タグ

【想定】
所在・通過・作業者・重複排除と読取漏れの検証。RFID通過 / 100タグを想定。

【生成内容・条件】
更新周期1000ms、最大tick数無制限。
100タグをGATE-IN, ASSEMBLY, INSPECTION, GATE-OUTの順に通過させ、3名の疑似作業者を割り当てる。1tickに5イベント、ラベル方式code128。

【確認事項】
tag_id・EPC・reader_id・operator_id・lot_idで通過を追跡し、event_idで重複を判定。
ラベルAPIでCode128/EAN13/QRのPNGを取得。実機リーダーのLLRP・RF無線通信は模擬せず、取り込み対象の読取イベントを再現。

【実行前】
公開・認証・送信先は別のプロファイルで指定し、保存後に停止・開始して適用。各条件はフォームとJSONで編集可能。
